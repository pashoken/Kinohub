# KinoHub TV v0.4.0

Первый публичный APK-релиз Android TV оболочки KinoHub.

## Что внутри

- настройка адреса домашнего сервера при первом запуске;
- управление пультом и TV-фокус;
- открытие видеопотока во внешнем Android-плеере;
- возможность изменить адрес сервера без переустановки APK;
- поддержка Android TV и Android-проекторов начиная с Android 6.0.

## Установка

1. Скачайте `kinohub-tv-0.4.0.apk` ниже.
2. Разрешите установку из неизвестных источников на TV/проекторе.
3. Установите APK и запустите KinoHub.
4. Введите адрес сервера, например `http://192.168.1.50:4100/`.

Перед установкой серверная часть KinoHub должна быть развёрнута по инструкции в README.

SHA-256 опубликована отдельным файлом `kinohub-tv-0.4.0.apk.sha256`.
