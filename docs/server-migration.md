# Перенос KinoHub на Ubuntu-сервер

## Граница этой инструкции

Локальная проверка не меняет удалённый сервер. Перенос выполняйте только после отдельного согласования окна работ, адресов дисков и резервной копии.

1. Установите поддерживаемые Docker Engine и Compose plugin на Ubuntu, создайте отдельный каталог `/opt/kinohub`.
2. Скопируйте репозиторий без `.env`, `node_modules` и тестовых артефактов. Создайте `/opt/kinohub/.env` с правами `600`.
3. Заполните `.env` и выполните `bash scripts/deploy.sh`; скрипт проверит Compose и дождётся healthcheck.
4. Проверьте `curl -fsS http://127.0.0.1:4100/api/health` и `KINOHUB_SMOKE_URL=http://127.0.0.1:4100 npm run smoke:docker`.
5. Публикуйте сервис в LAN только через отдельный reverse proxy с TLS и allowlist; не меняйте Compose-привязку `127.0.0.1` до проверки firewall.

Резервируйте перед каждым обновлением config-тома Seerr, Jackett и Jellyfin, а также настройки TorrServer. Для отката: остановить новый стек без `-v`, вернуть предыдущий image digest/Compose и восстановить только изменившиеся config-тома. Не обновляйте одновременно образы и схему хранения — это сохраняет ясную границу отката.
